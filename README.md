# Syner'JE Conseils — version avec photos

Site vitrine responsive prêt pour Netlify.

## DA
La structure s'inspire de Gazte Co. : navigation courte, hero éditorial, services, présentation de la Junior, démarche, ancrage territorial et CTA contact. Le traitement graphique est original pour Syner'JE : bleu profond issu du logo, turquoise, accents orange, typographie éditoriale, grands espaces et photos pleine largeur.

## Photos
- Saint-Pierre : photo publiée par la Mairie de Saint-Pierre (utilisée comme image distante).
- Piton de la Fournaise : Wikimedia Commons, fichier de Pouyot, CC BY-SA 4.0.
- Étudiants : Pexels, photo de Kampus Production, indiquée comme libre d'utilisation sur Pexels.
Les crédits sont affichés en bas du site. Vérifier les conditions de réutilisation si les images sont remplacées ou téléchargées localement.

## Netlify
Le formulaire est configuré avec Netlify Forms (`data-netlify="true"`). Après déploiement, les demandes reçues apparaissent dans Netlify.
